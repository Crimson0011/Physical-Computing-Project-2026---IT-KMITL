# บทคัดย่อ

Smart Parking เป็นระบบตรวจสอบสถานะช่องจอดรถ โดยใช้ Ultrasonic Sensor จำนวน 3 ตัว ติดตั้งไว้ในแต่ละช่องจอด เซนเซอร์จะส่งคลื่นเสียงออกไปและรับคลื่นที่สะท้อนกลับมาเพื่อคำนวณระยะห่างระหว่างเซนเซอร์กับวัตถุ เมื่อระยะทางไม่เกิน 10 เซนติเมตร หากระบบตรวจพบจะถือว่ามีรถจอดอยู่และแสดงเครื่องหมายกากบาท แต่ถ้าระยะทางมากกว่า 10 เซนติเมตร ระบบจะแสดงเครื่องหมายถูกเพื่อบอกว่าช่องจอดว่าง
Arduino จะประมวลผลข้อมูลจากเซนเซอร์ทั้ง 3 ตัว และแสดงผลบนหน้าจอ LCD 16×2 เพื่อให้ผู้ใช้งานทราบว่าช่องจอดใดว่างและช่องจอดใดมีรถจอดอยู่

# จุดประสงค์

1. เพื่อช่วยลดเวลาในการค้นหาช่องจอดรถ และเพิ่มความสะดวกให้แก่ผู้ใช้งาน

2. เพื่อศึกษาและใช้ความรู้ด้านไมโครคอนโทรลเลอร์ เซนเซอร์ และการเขียนโปรแกรมในการพัฒนาระบบอัตโนมัติ

3. เพื่อศึกษาและลองพัฒนาระบบตรวจสอบสถานะช่องจอดรถโดยใช้ Arduino UNO R4 WiFi , Ultrasonic Sensor และ LCD 16x2

สูตรคำนวณที่ใช้

$$
Distance = \frac{Time \times 0.03434}{2}
$$

Distance = ระยะทางระหว่างเซนเซอร์กับวัตถุ (cm)

Time = ระยะเวลาที่คลื่นเสียงเดินทางไปและกลับ (ms)

0.03434 = ความเร็วเสียงโดยประมาณ (cm/ms)

หาร 2 = เสียงเดินทางไปกลับ

เงื่อนไขการตรวจสอบที่จอดรถ

$$
Status =
\begin{cases}
\text{Unavailable}, & 0 < D \leq 10 \\
\text{Available}, & D > 10
\end{cases}
$$

หากอ่านค่าระยะทางไม่ได้ โค้ดปัจจุบันจะถือว่าช่องจอดว่าง (Available)
